# 014_math（仮名：けいさんぽ）

小学1年生と、字がまだ読めない未就学児のための算数アプリ。
毎日少しずつ「けいさん」の散歩をするイメージで、続けるほどほしが貯まり、キャラクターが育っていく。

## このフォルダの中身

| ファイル | 役割 |
|---|---|
| README.md | このファイル。全体の案内 |
| CLAUDE.md | Claude Code が守るルール（作業の進め方・技術の決まり） |
| PROMPT.md | Claude Code に最初に渡す指示文 |
| docs/REQUIREMENTS.md | 何を作るか（機能・画面・データ）の詳細 |
| docs/DECISIONS.md | なぜそう決めたか（決定事項と理由、未決事項） |

## 使い方

1. このフォルダで Claude Code を起動する
2. PROMPT.md の中身をそのまま貼り付けて送る
3. Claude Code は段階（フェーズ）ごとに止まって報告するので、確認してから「次へ」と伝える

## プロトタイプ（v0.1）の状態 — 2026-11-07

フェーズ1〜5の中身をひととおり作りました。ここから先の修正も、上の「使い方」と同じく Claude Code で進められます。

| ファイル | 中身 |
|---|---|
| index.html | アプリ本体（すべての画面・仕組みがこの1ファイルに入っている） |
| manifest.webmanifest / sw.js | ホーム画面に追加・オフラインで動かすためのファイル |
| icons/ | アプリのアイコン（SVG と PNG） |
| tools/test-generator.mjs | 問題の作り方の自動テスト |
| tools/render_icons.py | icon.svg から PNG を作り直す道具（ふだんは使わない） |

### パソコンで試す

- いちばん簡単：index.html をダブルクリック（オフライン化だけは動かない）
- 本番と同じ形で試す：このフォルダで `python -m http.server 8000` を実行し、ブラウザで http://localhost:8000 を開く

### テスト

`node tools/test-generator.mjs` を実行すると、4つの計算 × 5つの段階で5,000問ずつ問題を作り、けた数・答え・割り切れるか・4択の選択肢を確かめます。

### おうちの人の画面への入り方

ホームの右上 ⚙️ を3秒長押し → 初回は暗証番号（4けた）を決める。忘れたときは「暗証番号を忘れた場合」から、2けた×2けたの計算に答えると再設定できます。

### 更新して公開し直すとき

sw.js の `CACHE = 'keisanpo-v1'` の番号を上げてください（v2、v3…）。上げないと、すでに使っている端末では古い画面が出たままになります。

## 基本の形

- 1つのHTMLファイルが中心（＋PWA用の小さなファイル数個）
- ネットにつながなくても動く
- 記録は端末の中だけに保存。JSONで書き出し・読み込みができる
- GitHub Pages で公開
